This week I worked on implementing a character select screen with the two players we currently have set up. I implemented a few new scenes and created the UI for the scene and a working version of the character select that works locally.

Potentially in the future the system that allows you to select the player could change depending on the amount of players. This week's blockers were implementing the right UI sizing and ordering and learning how to use wrapi.

I estimated less time than it actually took to implement what I worked on. UI implementation takes longer than I had originally anticipated but I learned a lot from it. I was struggling with getting everything to look how I wanted but I ended up being able to achieve the goal I was tasked with

Communication with the team has been good overall. We are communicating via discord which has been easy and clear. We are all updating with progress and making it clear what we are working on.

Everything when commited to the GitHub has been useable and I have fixed any problems if any arose.
